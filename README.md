# Sofía González — Link-in-Bio Page (Astro.js)

Una página premium de enlaces Link-in-Bio construida con **Astro.js**, con diseño oscuro responsivo, slider de galería táctil, aviso y verificación de edad (+18) integrada, internacionalización (español/inglés) y píxel de seguimiento.

## 🚀 Características
- ⚡ **Desarrollado con Astro.js:** Renderizado súper rápido, ligero e hiper-optimizado.
- 🌍 **Internacionalización (i18n):** Soporte completo de traducción en Inglés y Español con detección de idioma del navegador y persistencia local (`localStorage`).
- 🔞 **Verificación de Edad (+18):** Popup y disclaimer glassmorphic que valida la mayoría de edad antes de redirigir a contenido exclusivo.
- 🎨 **Estilo Premium Glassmorphism:** Fondos degradados enriquecidos, efectos de desenfoque de fondo (glassmorphism) y animaciones de brillo responsivas.
- 📸 **Slider Táctil de Fotos:** Galería horizontal responsiva con controles de navegación para dispositivos móviles y de escritorio.

## 🛠️ Comandos de Desarrollo

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build

# Previsualizar la build de producción
npm run preview
```
